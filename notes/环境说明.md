## 三种用法

1. **VS Code 的 PowerShell 终端**（日常用这个）
   ```powershell
   cd D:\Code\cpp-learning\code\day01
   g++ hello.cpp -o hello     # 编译
   .\hello.exe                # 运行（PowerShell 必须写 .\ 和 .exe）
   ```
2. **MSYS2 终端**：双击 `D:\msys64\ucrt64.exe`，是个 UCRT64 环境（Linux 风格，命令写 `./hello`）
3. **装新工具**（只在 MSYS2 终端里做）：`pacman -S 包名`
   - 例：`pacman -S --needed mingw-w64-ucrt-x86_64-cmake`
   - 包名前缀统一是 `mingw-w64-ucrt-x86_64-`

## 踩过的坑

- **Hermes 的 Git Bash 里编译会静默失败（退出码 1、无报错）**：Git for Windows 自带的
  `/mingw64/bin` 里有同名 DLL，`cc1plus` 会加载错版本。不影响 VS Code 的 PowerShell 终端和
  MSYS2 终端，那两个都验证过能正常编译运行。
- **PATH 改完要重开终端**：VS Code 如果当时开着，重启一次（或新开窗口）才认新 PATH。
- **中文输出乱码**：Windows 控制台默认 GBK，程序里输出 UTF-8 中文可能显示成乱码。
  PowerShell 里临时解决：`[Console]::OutputEncoding = [Text.Encoding]::UTF8`
